# Créer un site web professionnel de calcul du score CPGE Maroc

Je veux que tu développes un **site web moderne, professionnel, rapide et entièrement responsive** permettant aux élèves marocains de calculer leur **score de sélection CPGE** à partir de leurs notes scolaires.

Le site doit être simple à utiliser sur **téléphone, tablette et ordinateur**, avec une interface claire et rassurante destinée principalement aux lycéens et candidats au CPGE au Maroc.

## 1. Objectif principal

L'utilisateur doit pouvoir :

1. sélectionner sa filière CPGE ;
2. renseigner ses informations scolaires ;
3. renseigner ses notes ;
4. obtenir automatiquement son score CPGE final ;
5. voir le détail du calcul étape par étape ;
6. comprendre exactement comment le score a été obtenu.

Le calcul doit être effectué automatiquement côté navigateur, sans nécessiter de compte utilisateur.

---

# 2. Formule officielle à implémenter

Le score final doit être calculé selon la formule :

**N = N1 + (N2 - 10) + (170 × N3 / 20) + (10 × N4 / 25)**

Afficher cette formule clairement dans la page "Comment ça marche".

Le site doit également afficher le résultat sous forme de composantes :

* N1
* N2
* N3
* N4
* Score final N

Les valeurs intermédiaires doivent être affichées afin que l'utilisateur puisse vérifier le calcul.

---

# 3. Calcul de N1 — Redoublement

N1 dépend du redoublement :

* **10/10** : l'élève n'a redoublé ni la première année du baccalauréat ni la terminale.
* **5/10** : l'élève a redoublé la première année du baccalauréat.
* **0/10** : l'élève a redoublé la terminale.

Créer une interface simple avec des boutons radio ou un sélecteur permettant de choisir la situation de l'élève.

L'utilisateur ne doit pas pouvoir sélectionner des combinaisons incohérentes.

---

# 4. Calcul de N2

N2 correspond à la combinaison des moyennes générales des deux années du baccalauréat.

Formule :

**N2 = (M1 + (2 × M2)) / 3**

Avec :

* **M1** = moyenne sur 20 de passage de la première année du baccalauréat à la terminale.
* **M2** = moyenne générale sur 20 du baccalauréat.

Créer deux champs numériques :

### M1

* minimum : 0
* maximum : 20
* accepter les décimales

### M2

* minimum : 0
* maximum : 20
* accepter les décimales

Afficher ensuite la valeur calculée de N2.

---

# 5. Calcul de N3

N3 représente la **moyenne pondérée des matières qualifiantes** correspondant à la filière CPGE sélectionnée.

Formule générale :

**N3 = (Note 1 × Coef 1 + Note 2 × Coef 2 + … + Note n × Coef n) / Total des coefficients**

Chaque note doit être comprise entre **0 et 20**.

Les matières affichées et leurs coefficients doivent changer automatiquement selon la filière sélectionnée.

# 8. Parcours utilisateur

Construire une expérience en plusieurs étapes.

### Étape 1 — Choisir le profil

Afficher :

**Quelle filière CPGE souhaitez-vous calculer ?**

Choix :

* MP
* PSI
* TSI
* ECS
* ECT

Après sélection, afficher les informations concernant les baccalauréats admissibles indiqués dans la source.

### Étape 2 — Redoublement

Demander la situation correspondant à N1.

Afficher immédiatement la valeur N1 obtenue.

### Étape 3 — Moyennes générales

Demander :

* M1
* M2

Afficher automatiquement N2.

### Étape 4 — Matières qualifiantes

Afficher dynamiquement les matières correspondant à la filière sélectionnée.

Chaque matière doit avoir :

* son nom ;
* son coefficient ;
* un champ de note sur 20.

Afficher également :

* somme pondérée ;
* total des coefficients ;
* N3.

### Étape 5 — Conseil de classe

Demander N4 sur 25.

### Étape 6 — Résultat final

Afficher une grande carte de résultat :

**Votre score CPGE**

**N = XX.XX**

Puis afficher le détail :

N1 = XX
N2 = XX
N3 = XX
N4 = XX

Et rappeler :

**N = N1 + (N2 - 10) + (170 × N3 / 20) + (10 × N4 / 25)**

# 10. Validation des données

Empêcher les valeurs incohérentes.

Pour les notes sur 20 :

**0 ≤ note ≤ 20**

Pour N4 :

**0 ≤ N4 ≤ 25**

Afficher des messages d'erreur compréhensibles en français.

Exemples :

* "Veuillez saisir une note."
* "La note doit être comprise entre 0 et 20."
* "La note du conseil doit être comprise entre 0 et 25."

Le score ne doit pas être calculé tant que les champs nécessaires ne sont pas valides.

---

# 11. Précision des calculs

Utiliser des nombres décimaux correctement.

Ne pas arrondir prématurément les valeurs intermédiaires.

Conserver les valeurs internes avec leur précision complète puis afficher le résultat avec **2 décimales**.

Exemple :

N3 peut être calculé avec sa valeur complète même si l'interface affiche 15.67.

# 15. Résultat détaillé

Le résultat doit être pédagogique et transparent.

Ne pas afficher uniquement un nombre.

Par exemple :

**Score final : 142.38**

Puis :

```text
N1 = 10
N2 = 16.40
N3 = 15.82
N4 = 21
```

Puis montrer le remplacement des variables dans la formule :

```text
N = 10 + (16.40 - 10)
    + (170 × 15.82 / 20)
    + (10 × 21 / 25)
```

Puis afficher le résultat final.

Cela permet à l'utilisateur de vérifier le calcul.
